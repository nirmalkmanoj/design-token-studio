# Design Token Studio — learning project

This is the first project in the [learning plan](LEARNING_PLAN.md). The current page contains semantic navigation, labeled token controls with native validation, and a component-preview card. Shared color and spacing tokens provide its initial styling.

## Preview the current page

Open `index.html` in a browser. Save a change in the editor and refresh the browser to see it. The page currently has no JavaScript behavior; `app.js` is empty and is not connected yet.

## Files

- `index.html`: page structure and text.
- `styles.css`: appearance, including shared CSS custom properties.
- `app.js`: reserved for later interactive behavior.
- `docs/`: session notes, concept tracker, and next step.

The project has no packages or build step at this stage. A local development server, tests, and deployment have not been set up yet.
